# Painel Mobilização Aqua – Enorsul

## Executar localmente
```bash
pip install -r requirements.txt
streamlit run app.py
```

A aplicação abre a planilha padrão incluída no projeto ou permite carregar outra versão `.xlsx` pela barra lateral.

## Publicação
Suba `app.py`, `requirements.txt` e a planilha para um repositório e publique no Streamlit Community Cloud.
